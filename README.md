# Knife Expert Website

Technologies Used:
- HTML
- CSS
- JavaScript

Description:
Knife Expert is a responsive website created using HTML, CSS, and JavaScript. 
It showcases a collection of knives and products with interactive features. 
The website includes:

- Home page with product showcase
- Responsive navigation menu
- Image gallery for products
- Smooth scrolling and interactive buttons

Purpose:
This project demonstrates front-end development skills, 
including layout design, styling, and DOM manipulation using JavaScript. 
It is part of my portfolio for internships in web development and front-end development.
